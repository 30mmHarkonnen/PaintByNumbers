# PaintByNumbers
Scale model paint matcher and color mixer

## Getting started

1. Download repo as a ZIP
2. Unzip `PaintByNumbers.zip` somewhere you can write to. Program is portable and self contained.
3. Double-click **`PaintByNumbers.exe`**.

## Matching a color

1. Click **Load image…** and open a photo (PNG, JPG, BMP, TIFF or WebP).
2. Click to sample colors. The program averages a 10 × 10 pixel area and shows the sampled color and its hex/RGB value at the bottom left.
3. Choose **Single** or **Blend**, set the filters you want (see below), and click **Match**.
